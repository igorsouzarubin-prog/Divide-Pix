# Divide Pix

Uma ferramenta gratuita, de código aberto e que funciona totalmente no navegador para dividir despesas em grupo e gerar uma mensagem pronta para enviar no WhatsApp.

## Por que existe?

Rachar uma conta costuma envolver calculadora, anotações e mensagens manuais. O Divide Pix reúne esses passos em uma página simples: informe o total, adicione as pessoas, defina contribuições diferentes quando necessário e copie o resumo.

Nenhum dado é enviado a servidores. As informações ficam apenas no navegador da pessoa usuária.

## Como usar

1. Abra `index.html` em qualquer navegador moderno.
2. Informe a despesa e as pessoas participantes.
3. Opcionalmente, registre quanto cada pessoa já pagou.
4. Copie o resumo gerado.

## Desenvolvimento

Não há dependências nem instalação. O projeto é HTML, CSS e JavaScript puro, para poder ser usado e adaptado facilmente.
